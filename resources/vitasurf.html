Cloudflare browser checks

Pages titled "Just a moment..." are Cloudflare's browser check, which this browser cannot pass on its own. Run FlareSolverr on a computer on the same network and write its URL (for example http://192.168.1.20:8191/v1) into the file ux0:data/VitaSurf/flaresolverr; the check is then handed to it and the page reloads.

Each load writes its time and the heap used to the log.

The log is written to ux0:data/VitaSurf/log.txt. Create an empty file named verbose in that folder for a detailed log.
